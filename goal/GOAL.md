# 目标：大阪城全城 3D 复刻（德川期布局 + 丰臣式天守）

## 验收标准（全部满足 = 完成）
1. **布局**：俯视图 `top.png` 与参考航拍 `refs/Osaka_Castle_Aerial_photograph_2017.jpg` 对比，外堀/内堀/本丸/二之丸/西之丸轮廓一致，没有多出或缺失的大块陆地。
2. **石垣**：所有临水面为带倾斜（扇勾配，顶部内收约 15–25%）的石垣，有可辨识的石块质感；本丸东面从水面到顶部明显高耸（eastwall 视角）。
3. **地形高差**：本丸 > 二之丸 > 城外，曲轮之间有坡道/土桥连接，人眼看起来合理。
4. **现存建筑**：大手门（含高丽门与枡形）、多闻橹、千贯橹、乾橹、一番橹、六番橹、樱门、青屋门、焔硝蔵、金蔵、金明水井户屋形 均有可辨识的造型（白漆喰墙、本瓦屋顶、破风），比例合理。
5. **已毁橹**：遗址点上的三重/二重橹可按“江户盛期”模式补建，查看器可切换“现状 / 江户盛期”。
6. **天守**：丰臣式天守坐落在天守台上，与本丸地面衔接自然，尺度合理（总高约 40–58 m）。
7. **植被与细节**：树木分布贴近航拍（西之丸草坪开阔、二之丸林地），有道路/广场。
8. **查看器**：离线 HTML 打开即可浏览，有视角预设（全城、大手门、天守、东面石垣）、标签可开关、帧率可用（GLB ≤ 25 MB）。

## 约束
- Mac 上 Blender 无界面构建是权威产出；单轮构建 ≤ 120 秒。
- 只在 ~/Hark/ 下读写。仓库 github.com/changrong996-droid/osaka-castle-3d 是公开的。
