# 杭州西站图册 · 第一阶段任务卡附则

本附则记录委托人对远景备忘录（docs/hz-vision-memo.md）§3.4 三项冲突的裁定，以及第一阶段把关意见中与卡面不冲突的澄清条款。裁定日期：2026-11-07。

适用关系：本附则不修改方向备忘录（docs/hz-direction-memo.md）原文。执行 HZ-03、HZ-05 时，卡面与本附则一并适用；两者表述不一致处，以本附则为准。

## 第一部分 裁定修订

### A1（HZ-05）实物记录增加可选字段 anchor

- HZR 记录新增可选字段 `anchor`，位置在 `cam` 之后、`note` 之前。
- 类型：string 或 null，默认 null，非必填。
- 取值：一个 `#focus=` 值（J23、ZN、ZM、ZS、CUT、GAP 之一），或一个活动键（HZ.K 的键）。
- check_real 仅在 `anchor` 非 null 时校验其可解析（能对应到上述焦点值或活动键）；为 null 时不作任何要求。

### A2（HZ-05）src.url 放宽以收自有素材

- `src.url` 的合法形态为以下三类之一：
  1. 以 `http://` 或 `https://` 开头的外链；
  2. 仓库相对路径（例如以 `real/` 开头）；
  3. 空字符串——此时 `license` 必须为 `own`（自有素材尚未入库时使用此形态）。
- check_real 按上述三类校验，不再只认外链。

### A3（HZ-03）增加 HZA.PROJECT 常量

- 登记表新增顶层常量 `HZA.PROJECT = 'HZW'`。
- SHEETS 编号断言改为 `no === HZA.PROJECT + '-' + 键`；`resolve` 解析图号时剥去 `HZA.PROJECT + '-'` 前缀。
- 图号规范记为 `<项目码>-S-<页号>-<子图序号>`，西站项目码取 `HZW`。
- 除登记表自身的常量定义外，代码中不得再出现写死的 `'HZW-'` 字面量。

## 第二部分 把关澄清（与卡面不冲突，执行时一并适用）

### C1（HZ-05）t 字段约束以远景备忘录 §3.2 第 2 条为准

- `t` 是与记录内容所对应的施工状态在模型中的时刻，**不由 `date` 换算得出**；`date`（实际日历尺）与 `t`（模型时刻）是两把独立的尺。
- `t` 为 null 表示尚未对齐；`t` 可为小数。
- check_real 不得断言 `t` 与 `date` 之间存在任何换算或相等关系；当一条记录的 `date` 与 `t` 均非 null 时，在 OK 行打印两者偏差（天）。

### C2（HZ-05）未知字段只警告、字段顺序不断言

- check_real 对字段表中未列出的键只给出警告（warn），不报错。
- check_real 不对字段顺序做任何断言。

### C3（通用）西站专属断言须标明为项目级检查

- check_atlas、check_real 中的西站专属断言，须在脚本头部注释中标明「项目级检查，不属于内核」。
