# 城内建筑：建筑语法（web-r9 / B1，室内细部 web-r11 / B3）与来源表

`web/bldg.js` 用一份规格（`SPEC`）按规则生成城内建筑：外观和内部来自**同一份**格网规格（0.5 間格，1 間 = 1.97 m），没有手写坐标。规则与审计见 [RULES.md](RULES.md) §7；这里是**每一类建筑用了什么数据、哪些是推定**。

## 1. 两级可信度

| 级别 | 含义 | 本轮属于这一级的 |
|---|---|---|
| **实测（strict）** | 位置/外形/尺寸来自测量或指定文化财数据，生成器不改 | 地形、石垣（r1–r8）；现存 4 座橹的位置（site 部件）、外形（OSM）、层数、各层面积、高度；丰臣式天守外观 |
| **推定（generated）** | 无文献或文献只给类型/名称：规则 + 种子在范围内取值，每栋带 `prov`（`b.prov.tier = '推定'`、`note` 写依据） | 失传橹的外观与全部内部；现存橹的**内部**；本丸御殿、番所、蔵（位置、平面、房间、开口） |

页面面板的下拉框里每栋标“实测外观”或“推定”。“推定”不是“猜坐标”：位置由空地 + 退距规则推出，尺寸在下表的范围内按种子取，审计 H22–H27/C9–C10 保证物理上成立。

## 3. 推定范围（`SPEC`）

| 参数 | 值 | 理由 |
|---|---|---|
| 格 | 0.5 間 = 0.985 m | 畳 = 2×1 格；柱筋在偶数格线上 |
| 橹层高 | 3.4–4.8 m（现存橹由实测总高反推） | 失传三重櫓总高 18–20 m、二重 12–14 m |
| 橹上层内收 | 每侧 0.5–1 間（三重櫓 0.5 間：13×11 m 的槽位里顶层仍放得下階段） | 逓減（柱筋相通） |
| 入側（武者走り） | = 上层墙线外的一圈；総二階/顶层取 1 間；身舎 <24 格则整层一间 | 乾櫓“内室 3 + 武者走り 1 間”的类型 |
| 御殿殿舍 | 宽 8–18 間、深 6–13 間（按殿舍名分档），墙高 3.5–4.2 m，屋顶坡 0.62，出檐 1.6 m | 書院造大殿的量级；廊下宽 1.5 間 |
| 階段 | 坡度 45°–55°（1.0–1.43）、踢面 0.15–0.25 m、净高 ≥1.9 m、宽 1 間（web-r11：千貫櫓 复原木階段约 56°，见 §5） | 城郭急階段 |
| 门洞 | 净高 1.8 m、宽 ≥1 間（外门）；室内隔断开口 ≥半間 | 内法约 6 尺 |
| 梁跨 | ≤3 間 | 与 site 的桥跨同源 |

## 4. 数量（seed 1，江戸盛期）

26 栋：橹 21（实测外观 4 + 推定 17；三重 10、二重 11）、本丸御殿 1（7 殿舍 + 6 廊下；台所放不下，见 RULES §7 剩余问题）、番所 2、蔵 2；186 室、930 畳。现状模式只有 4 座现存橹（内部推定）。

## 5. 室内细部（web-r11 / B3）：窓・階段・木组・材质

内外同一份开口表（H27）；窓是**墙上的真洞**（墙厚 0.24 m 的侧面 = 見込み），格子/土戸/障子 是同一组几何，从里从外看到的是同一个东西，阳光与窓外的景色都从洞里进来（H29 用穿过洞口的射线网格检查通视）。

| 元素 | 规则（`SPEC`） | 来源 | 级别 |
|---|---|---|---|
| 橹的窓 = **塗籠格子窓 + 土戸（引戸）** | 洞 1.2 × 0.95 m、窓台 0.85 m；灰泥竖格子 0.11 m 见方、见込み 0.12 m、缝 0.13 m（规则：缝 0.06–0.2 m）；土戸 0.08 m 厚、滑到相邻一間的墙前（引き代 = 窓宽 → 窓不相邻） | 千貫櫓「横矢掛の格子窓や鉄砲狭間」「土戸」[^sfo4]；乾櫓「扉は…土戸」「窓は 26 箇所」[^sfo6] | 类型 = 实测/文献；尺寸 = 推定 |
| 千貫櫓 城内侧不开窓 | `measured['千貫櫓'].winIn = false`：窓只在城外侧两面 | 「本来、千貫櫓の東面・北面には窓がひとつも無い」，东/北面的窓是明治陆军加的、1961 修理时拆除[^sfo4] | 实测 |
| **隠狭間** | 城外侧墙上不被门/窓/石落し/土戸引き代 占的間位，形状 丸/三角/四角 轮换；外面灰泥封皮（从外看不见）、里面开口；千貫 1 階 ≤11、2 階 ≤8，乾 每层 ≤8 | 千貫櫓 隠狭間「城外側のみ…西側、南側ともに 4 個（1 階は西側 6 個、南側 5 個）」[^sfo4]；乾櫓「隠し狭間が 16 門」[^sfo6] | 数量上限 = 实测；位置 = 规则 |
| 石落し | 城外侧两面中部各一处（同 web-r9） | 乾櫓「石落としが 4 箇所城外側のみ」[^sfo6]、城市资料[^city] | 实测类型 |
| 華頭窓 | 仅失传三重橹顶层城内侧中央一扇（格子 + 内外两面華頭形木板） | 大坂城现存橹没有華頭窓；三重櫓顶层的装饰惯例 | **推定** |
| 番所的窓 = 突上戸 + 木格子 | 板窓上端铰接、外撑 0.6 rad + 撑棍 | 板壁小建筑的惯例 | **推定** |
| 御殿外墙 = 明障子 引違い | 敷居/鴨居 + 两扇障子（組子纹理、透光），两扇都推到一侧 = 半开（看得见外面） | 書院造入側的惯例 | **推定** |
| **階段** | 坡度 45°–55°（`slopeMin 1.0 … slopeMax 1.43`）、踢面 0.15–0.25 m、净高 ≥1.9 m；开放踏板（不做踢板）0.045 m 厚 + 0.03 m 出鼻，两侧側桁 0.06 × 0.26 m，开放侧手摺 0.85 m；上层階段口（VOID）四周手摺（上楼口除外） | 千貫櫓の木階段 = 1961 年按原状复原：「二間弱の距離を使い急勾配・傾斜角約 56 度」，明治陆军的 35° 缓阶段是后加的；階段上部の水平引戸も復元[^sfo4] | 坡度范围 = 文献；板厚/側桁/手摺 = 推定 |
| 武者走り の露出木组 | 外墙每間柱一根繋梁（0.2 × 0.3 m）跨过入側到身舎线 + 沿墙方向根太（间距 0.45 m）；梯段上方不设 | 千貫櫓 1 階「頭上の木組み…武者走りと平行に設置された材」[^sfo4] | 类型 = 文献；尺寸 = 推定 |
| 天井 | 橹内室 = 竿縁天井（板）；武者走り = 板 + 露出木组；御殿畳间 = 竿縁、上段之間 = 格天井 | 千貫櫓「回廊の内側に 4 室ずつの天井板張りの部屋」[^city]；御殿 = 書院造惯例 | 橹 = 文献；御殿 = 推定 |
| 畳 / 長押 | 畳 2 × 1 格，縁 在两长边；御殿房间与外墙内侧 長押 0.12 m | 惯例 | 推定 |
| 材质 | 运行时 canvas 程序纹理（木纹、0.3 m 床板、灰泥、藺草 + 縁、竿縁/格天井、組子障子、襖），盒子按最长边出木纹方向的米制 UV；不进包、无图片文件 | — | — |
